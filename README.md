Activity Management System (CRUD Web Application)

Developed a dynamic web application that allows users to manage and organize activities
through a user-friendly interface. The frontend was built using React with TypeScript to
ensure type safety and improve code maintainability. The application enables users to 
create, read, update, and delete (CRUD) activities seamlessly.

On the backend, a robust API was developed using C# and the .NET framework to handle data
requests and business logic. The API ensures secure and efficient communication between 
the frontend and the database, allowing for real-time updates and data persistence.
